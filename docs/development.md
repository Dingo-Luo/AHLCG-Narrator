# 开发说明

本项目从现在起只维护中文内容。基础版、敦威治与卡尔克萨的内容分别保存在 `data/core.json`、`data/dwl.json`、`data/ptc.json`，卡牌和剧情直接使用中文字段。优先保留已有简体译文，缺少简体的字段保留已有繁体译文；不做字符转换。缺少中文的字段用中文提示占位，位置记录在 `data/chinese-content-audit.json`。

英文原文库、原始上游快照、PO 文件、英文翻译键及旧版联网导入脚本已移除。后续直接编辑中文内容文件，不再通过英文原文匹配译文。`npm run check:content` 检查中文字段和现有卡图校验值；`npm test` 验证战役流程、存档、导航、历史记录及内容格式。

仍保留英文卡图，因为目前没有对应中文图片。卡图旁直接显示中文文字，配音入口只接受中文音频；实际音频尚未加入。

代码标识符、剧情和卡牌 ID、条件枚举、规则特征值、来源版本、URL、校验值与作者署名为技术或来源资料，保持原样。规则特征值供剧情筛选使用，不作为英文文案展示。存档格式、事件 ID 和战役来源版本不变；已有存档继续重放。动态日志使用条目 ID 判断含义，不再检查英文句子。

`data/*-sources.json` 与 `data/sources.json` 保留来源版本和卡图归属信息，不再声明本地保存原始上游文件。署名见 `THIRD_PARTY.md`。

## 配音索引

配音字段、永久编号、脚本重建与本地音频映射见 `docs/narration.md`。卡牌旧 `audio` 字段不再用于整张卡牌播放，音频按段落编号在 `data/narration/audio.json` 登记。新增或改动正文后运行 `npm run build:narration`，提交更新的 `data/narration/index.json` 和 `docs/配音脚本.md`，再运行检查。
